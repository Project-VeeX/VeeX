# VeeX 过程

VeeX 的过程以阶段切换为主轴。

## 阶段

`Dormant`

初始阶段。
结构已存在，但尚未形成明显推进。

`Active`

过程开始升温。
偏移与增量会在这一阶段被放大。

`Aligning`

校准阶段。
局部不一致被重新拉回同一范围。

`Converging`

收敛阶段。
异常残留被持续吸收，结构趋于稳定。

`Stabilized`

稳定阶段。
整体回落，变化幅度受控。

## 高活跃区

高活跃区通常出现在中段。

此时记录密度上升，偏移短暂抬高，观测会标记警示。
该区域不会持续停留，只作为短时峰值出现。

## 稳定域

稳定域不是静止。

它表示结构已回到可预期范围，局部变化仍然存在，但不会继续扩散。
当阶段进入 `Stabilized` 时，系统已回落至稳定域。
