# VeeX 结构

VeeX 由五个部分组成。

整体不追求层级堆叠，而是维持清晰分工。
状态推进、过程组织、表达生成与记录归档分别承载，不交叉扩散。

## veex-signal

`veex-signal` 负责基础状态。

这里保存阶段、稳定度、偏移值与记忆快照。
任何周期推进都以这一层为基准。

## veex-orbit

`veex-orbit` 负责周期组织。

它决定何时进入活跃、何时执行校准、何时转入收敛。
过程中的短暂失衡也在这里被处理。

## veex-echo

`veex-echo` 负责上下文与表达。

它不主导状态，只读取当前状态并生成简洁表达。
表达保持克制，用于标注当前阶段的可见结果。

## veex-archive

`veex-archive` 负责记录。

关键变化会形成事件，短期片段会进入最近记录，整体结果会汇总为归档摘要。
记录只保留必要部分。

## veex-terminal

`veex-terminal` 负责演示入口。

它启动周期，逐轮呈现状态，并在结束时输出最终摘要。
终端只展示结果，不展开内部细节。
